# Aerospace Engineering Portfolio

A responsive, static portfolio website built with plain HTML, CSS, and JavaScript. It has no paid dependencies, frameworks, build tools, or external fonts.

## Preview locally

1. Extract this folder if you downloaded the ZIP.
2. Open `index.html` in a modern browser.

For a local development server (optional), open a terminal in this folder and run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`. Stop the server with `Ctrl+C`.

## Personalise before publishing

Search the files for `YOUR NAME`, `your.email@example.com`, and `yourname.github.io` and replace the placeholders.

- Update the page title and description in `index.html`.
- Add your real LinkedIn profile URL and contact email.
- Add your resume PDF to this folder, for example `resume.pdf`, then change the Resume link to `href="resume.pdf"`.
- Replace each project placeholder with accurate project details, your contribution, methods, results, and relevant images.
- The diagrams are illustrative. Do not describe them as measured or simulated results.
- Only publish project work you have permission to share.

## Publish free with GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io` (replace with your actual username).
3. Upload `index.html`, `style.css`, `script.js`, and any assets you want to publish to the repository's root.
4. In the repository, open **Settings → Pages**.
5. Under the build/deployment section, select **Deploy from a branch**.
6. Select the `main` branch and `/(root)`, then save.
7. Wait for the deployment to finish. Your website address will be `https://YOUR-GITHUB-USERNAME.github.io`.

GitHub Pages can take a few minutes to publish the first time. Check the Actions tab or Settings → Pages if it does not appear.
